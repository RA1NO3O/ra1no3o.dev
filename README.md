# ra1no3o.dev

Personal site. Astro builds it to static HTML in English, Simplified Chinese, Traditional Chinese, and Japanese. `/` redirects to `/en`.

```sh
npm install
npm run dev
npm run build
```

`dist/` is the site. Cloudflare Pages project `ra1no3o-dev` hosts that directory by direct upload. GitHub does not build it.

Day-to-day edits, the four locales, icons, and the deploy command are in [docs/维护.md](docs/维护.md).
